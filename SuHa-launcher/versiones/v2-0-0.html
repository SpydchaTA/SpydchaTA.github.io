Notas de version v2.0.0

Mas modloaders para el cliente

Hola soy Spy y les presento las nuevas notas de versión v2.0.0

Mejora en las versiones

  • Se ha agregado compatibilidad con nuestro Mod para la precensia de discord.
    • Se agregaron nuevas mecánicas que permiten mostrar cuando un usuario está dentro de un mundo y en cuál dimensión, y muchas más características.

Mejora en la interfáz

  • Hemos notado que la interfáz se veía tosca y molesta. Asi que se ha mejorado el diseño de manera que esté sea mas amigable para el usuario
    • Se ha agregado un nuevo diseño para el launcher, con colores más llamativos y un diseño más amigable para el usuario.
    • Ahora en tus cuentas se ve una pre-visualización de tu Skin.

Nueva forma para lanzar el juego

  • Antes la gente solia confundir la sección de instalación de versiones con la de lanzamiento, lo que provocaba que el usuario instalara una versión por accidente tratando de ejecutarla
    • Ahora se ha agregado un nuevo sistema para instalar versiones mas apartado del lanzamiento, el cual es más facil de usar y no confunde al usuario.
    • Por el momento solo se pueden instalar versiones vanilla. Proximamente se añadira la compatibilidad con forge, fabric y neoforge
Gracias por confiar en nosotros y esperamos que les guste este launcher.
